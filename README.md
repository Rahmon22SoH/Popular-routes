# Маршруты Кавказского заповедника

Сайт с популярными пешими маршрутами Кавказского биосферного заповедника. На карточке маршрута есть описание, фото и карта: линия пути и точки стоянок с фотографиями.

Проект собран вместе с [Артуром Газизовым](https://github.com/artur8833). Исходная версия жила в форке `artur8833/Popular-routes`. Этот репозиторий — отдельная копия для доработки и портфолио: история коммитов сохранена, пометка «fork» убрана.

## Что есть на сайте

- главная страница с карточками маршрутов и фильтром по району, сложности и названию;
- страница маршрута с фото и картой Folium;
- регистрация и вход;
- админка Flask-Admin для новых маршрутов, координат и фото;
- пять стартовых маршрутов заповедника, они попадают в базу командой `flask db upgrade`;
- погода в Сочи, если указан ключ WorldWeatherOnline. Без ключа сайт открывается, в меню будет «Погода недоступна».

## Запуск на Windows

```bat
python -m venv env
env\Scripts\activate
pip install -r requirements.txt
copy webapp\config.example.py webapp\config.py
set FLASK_APP=webapp
flask db upgrade
flask run
```

Сайт откроется на http://127.0.0.1:5000

На Linux и macOS те же шаги, только окружение активируется через `source env/bin/activate`, а конфиг копируется так: `cp webapp/config.example.py webapp/config.py`. Либо запустите `./run.sh` после `chmod +x run.sh`.

## Настройка

В `webapp/config.py`:

- `SQLALCHEMY_DATABASE_URI` — по умолчанию файл `db.sqlite3` в корне проекта;
- `WEATHER_API_KEY` — ключ с [worldweatheronline.com](https://www.worldweatheronline.com/);
- `SECRET_KEY` — любая длинная случайная строка.

Файл `webapp/config.py` не коммитится.

## Регистрация и админка

Кнопка «Регистрация» на сайте создаёт обычного посетителя. Такой аккаунт может войти, но пункта «Админка» у него нет, и адрес `/admin` его не пускает.

Администратора через форму на сайте создать нельзя. Его заводят один раз в консоли, из папки проекта, при запущенном виртуальном окружении:

```bat
python create_admin.py
```

Скрипт спросит имя и пароль и запишет пользователя с ролью `admin`. После этого на сайте нажмите «Войти» и укажите эти же имя и пароль. В меню появится «Админка», она открывается по адресу http://127.0.0.1:5000/admin

Если это имя уже занято обычной регистрацией, скрипт остановится. Возьмите другое имя или удалите этого пользователя из базы.

Новые маршруты, тексты и фото добавляются уже внутри админки. Пять маршрутов заповедника создаются сами при `flask db upgrade`. Координаты линии можно также загрузить файлом GeoJSON на страницу `/load/<id>`, где `<id>` — номер маршрута. Эта страница тоже только для администратора.

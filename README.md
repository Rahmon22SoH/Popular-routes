# Маршруты Кавказского заповедника

Сайт с популярными пешими маршрутами Кавказского биосферного заповедника. На карточке маршрута есть описание, фото и карта: линия пути и точки стоянок с фотографиями.

Проект собран вместе с [Артуром Газизовым](https://github.com/artur8833). Исходная версия жила в форке `artur8833/Popular-routes`. Этот репозиторий — отдельная копия для доработки и портфолио: история коммитов сохранена, пометка «fork» убрана.

## Что есть на сайте

- главная страница с карточками маршрутов и фильтром по району, сложности и названию;
- страница маршрута с фото и картой Folium;
- регистрация и вход;
- админка Flask-Admin для новых маршрутов, координат и фото;
- пять стартовых маршрутов заповедника, они попадают в базу командой `flask db upgrade`;
- погода в Сочи, если указан ключ WorldWeatherOnline. Без ключа сайт открывается, в меню будет «Погода недоступна».

## Запуск на Windows

```bat
python -m venv env
env\Scripts\activate
pip install -r requirements.txt
copy webapp\config.example.py webapp\config.py
set FLASK_APP=webapp
flask db upgrade
flask run
```

Сайт откроется на http://127.0.0.1:5000

На Linux и macOS те же шаги, только окружение активируется через `source env/bin/activate`, а конфиг копируется так: `cp webapp/config.example.py webapp/config.py`. Либо запустите `./run.sh` после `chmod +x run.sh`.

## Настройка

В `webapp/config.py`:

- `SQLALCHEMY_DATABASE_URI` — по умолчанию файл `db.sqlite3` в корне проекта;
- `WEATHER_API_KEY` — ключ с [worldweatheronline.com](https://www.worldweatheronline.com/);
- `SECRET_KEY` — любая длинная случайная строка.

Файл `webapp/config.py` не коммитится.

## Регистрация и админка

Кнопка «Регистрация» на сайте создаёт обычного посетителя. Такой аккаунт может войти, но пункта «Админка» у него нет, и адрес `/admin` его не пускает.

Администратор создаётся сам при запуске сайта. Отдельный скрипт для этого не нужен. Нажмите «Войти» и введите:

- имя: `admin`
- пароль: `kavkaz2026`

После входа в меню появится «Админка»: http://127.0.0.1:5000/admin

Репозиторий публичный, поэтому этот пароль не секрет: его видит любой, кто читает README. Для локального каталога и портфолио этого достаточно. Если выложите сайт в интернет, смените пароль у пользователя `admin` в базе. Пока имя `admin` уже есть, сайт пароль сам не перезаписывает.

Скрипт `python create_admin.py` остаётся только если нужен второй администратор. Он спросит имя и пароль не короче 8 символов.

Регистрация на сайте просит имя, почту и пароль. Пароль в базе хранится только как хеш, роль из формы выбрать нельзя, чужая форма без секретного токена сайта не принимается. Это защита локального сайта, не сервис с подтверждением почты и ограничением числа попыток входа. В `webapp/config.py` замените `SECRET_KEY` на длинную случайную строку.

Админка на русском. Первая страница объясняет порядок: карточка, описание, линия, карта, фото, метки. У каждой вкладки сверху есть подсказка. Второе описание к одному маршруту не сохранится: это запрещено и формой, и базой. Удаление карточки, фото или метки убирает и файл из папки `media`, если его не использует другая запись.

## Как добавить координаты

Линия на карте собирается из точек. Их вводят во вкладке «Линия на карте» или заливают файлом.

1. Откройте [Яндекс.Карты](https://yandex.ru/maps) или Google Maps и найдите место на тропе.
2. В Яндекс.Картах нажмите правой кнопкой и выберите «Что здесь?». В Google Maps координаты стоят первой строкой меню по правому клику.
3. Пара выглядит так: `43.5492, 39.8231`. Первое число — широта, второе — долгота.
4. Для Сочи и Красной Поляны широта около 43.5–43.7, долгота около 39.8–40.6. Если первое число около 40, поля перепутаны.
5. Пишите точку, не запятую: `43.55`, а не `43,55`.
6. В админке нажмите «Создать». Выберите маршрут. Порядок `0` — старт, следующая точка — `1`, дальше по ходу тропы.
7. Нужны минимум две точки. Ставьте их на старте, поворотах и финише: чем чаще излом тропы, тем точнее линия.
8. Кнопка «Сохранить и добавить новый объект» сразу открывает следующую точку.
9. Вкладка «Карта» показывает результат, не выходя из админки.

Готовую линию можно загрузить файлом GeoJSON на страницу `/load/номер`, где номер — это id маршрута из списка. В файле координата записана как долгота, широта; сайт ставит их в поля сам. Повторная загрузка заменяет все точки этого маршрута. Страница только для администратора.

Пять маршрутов заповедника создаются сами при `flask db upgrade`.
